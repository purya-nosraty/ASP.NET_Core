## About

This repository contains an ASP.NET Core solution intended as a starting point for web applications. It appears to include front-end assets in addition to .NET server code.

## Features

* ASP.NET Core backend (solution-based layout)
* Front-end assets (Bootstrap, JavaScript, HTML, CSS) in `src`
* Ready to add EF Core migrations, unit tests, Docker support, and CI workflows

## Prerequisites

* .NET SDK 6.0+ (recommended: .NET 7 or 8). Check with:

```bash
dotnet --version
```

* Local DB (SQL Server, SQLite, PostgreSQL) if the app uses EF Core
